## 1. Contexte & Problématique Actuelle

1. **Couplage rigide à Google Cloud Logging (`utils/gcp_logging.py` & `utils/obsidian_monitor.py`)** :
   - `MirrorAgentLogger` exécute `self.client = google.cloud.logging.Client()` sans vérifier si un projet GCP est configuré, provoquant une `DefaultCredentialsError` sur un poste local non authentifié à GCP.
2. **Couverture de tests unitaires quasi inexistante (`tests/unit_tests/`)** :
   - `tests/unit_tests/test_configuration.py` contient une seule ligne sans assertion (`Configuration.from_runnable_config({"user_id": "foo"})`).
3. **Métrique d'évaluation RAG biaisée (`utils/eval_rag_pipeline.py`)** :
   - La distance de Levenshtein globale (`Levenshtein.distance(expected_text, doc_text) / max(...)`) entre une réponse courte attendue et un segment de 3000 caractères plafonne mathématiquement le score autour de `0.03`, rendant le seuil `score > 0.8` impossible à atteindre.

## 2. Spécifications Techniques

### A. Observabilité Hybride & Découplée de GCP (`utils/gcp_logging.py`)

```python
import json
import logging
import os
from typing import Any, Dict, Optional

logger = logging.getLogger("mirror-agent")


class MirrorAgentLogger:
    """Structured logger with optional GCP Cloud Logging backend and local fallback."""

    def __init__(self, log_name: str = "mirror-agent") -> None:
        """Initialize the logger with automatic fallback to standard Python logging."""
        self.log_name = log_name
        self.start_time: Optional[float] = None
        self._gcp_logger = None

        if os.getenv("ENABLE_GCP_LOGGING", "").lower() in {"1", "true", "yes"}:
            try:
                from google.cloud import logging as gcp_logging

                client = gcp_logging.Client()
                self._gcp_logger = client.logger(log_name)
            except Exception:
                logger.warning("GCP credentials unavailable; falling back to local structured logging.")

    def _emit(self, payload: Dict[str, Any], severity: str = "INFO") -> None:
        """Emit structured log entry to GCP if enabled, otherwise to standard logger."""
        if self._gcp_logger is not None:
            self._gcp_logger.log_struct(payload, severity=severity)
        else:
            level = getattr(logging, severity.upper(), logging.INFO)
            logger.log(level, json.dumps(payload, ensure_ascii=False))
```
