## 2. Spécifications de Refonte

### A. Initialisation Paresseuse (*Lazy Singleton*) et Mode Hybride Cloud / Local de `Mem0Memory`

Dans `mem0ai`, il existe deux moteurs distincts :
1. **`MemoryClient` (`from mem0.client.main import MemoryClient`)** : Le client SaaS Cloud (nécessite `MEM0_API_KEY`, `MEM0_ORG_ID`, `MEM0_PROJECT_ID`).
2. **`Memory` (`from mem0 import Memory`)** : Le moteur open-source **100 % local** qui s'exécute directement dans la boîte Python en utilisant **ChromaDB** local (`data/chroma_mem0`), les embeddings `BAAI/bge-large-en-v1.5` déjà présents dans le projet et **Ollama** (ou OpenAI), **sans aucune clé `MEM0_API_KEY`**.

Au lieu d'instancier `Mem0Memory()` de façon rigide lors de l'import de `state.py` :
1. **`Mem0Memory` (`src/retrieval_graph/mem0_client.py`)** devient **hybride** :
   - Si `MEM0_API_KEY` est défini $\rightarrow$ utilise `MemoryClient` (Cloud Mem0).
   - Sinon, si `MEM0_MODE="local"` $\rightarrow$ initialise `Memory.from_config(...)` sur ChromaDB local (`data/chroma_mem0`).
   - `MEM0_USER_ID` utilise une valeur par défaut sûre (`"default-user"`) au lieu de lever une `ValueError` bloquante à l'import.
2. **`state.py`** utilise un accesseur paresseux `get_mem0_client() -> Optional[Mem0Memory]` et rétablit l'héritage `class State(InputState):` :

```python
import logging
import os
from dataclasses import dataclass, field
from typing import Annotated, Any, Literal, Optional, Sequence, Union

from langchain_core.documents import Document
from langchain_core.messages import AnyMessage
from langgraph.graph import add_messages

from .mem0_client import Mem0Memory

logger = logging.getLogger(__name__)
_mem0_instance: Optional[Mem0Memory] = None


def get_mem0_client() -> Optional[Mem0Memory]:
    """Return a lazily initialized Mem0Memory instance if credentials are configured."""
    global _mem0_instance
    if _mem0_instance is not None:
        return _mem0_instance

    if not (os.getenv("MEM0_API_KEY") and os.getenv("MEM0_USER_ID")):
        logger.debug("Mem0 credentials not set; operating with local in-memory state.")
        return None

    try:
        _mem0_instance = Mem0Memory()
        return _mem0_instance
    except Exception:
        logger.exception("Failed to initialize Mem0Memory client; falling back to local state.")
        return None
```

2. **Suppression de `pickle` et initialisation paresseuse de `CohereRerank`** dans `src/retrieval_graph/retrieval.py` :

```python
from functools import lru_cache


@lru_cache(maxsize=4)
def load_embeddings_model(model_name: str = "BAAI/bge-large-en-v1.5") -> HuggingFaceEmbeddings:
    """Load and cache a HuggingFaceEmbeddings instance in memory without pickle."""
    import torch

    device = (
        "cuda"
        if torch.cuda.is_available()
        else ("mps" if hasattr(torch.backends, "mps") and torch.backends.mps.is_available() else "cpu")
    )
    return HuggingFaceEmbeddings(
        model_name=model_name,
        model_kwargs={"device": device},
        encode_kwargs={"normalize_embeddings": True},
    )


@lru_cache(maxsize=1)
def get_cohere_reranker() -> Optional[CohereRerank]:
    """Lazily initialize CohereRerank only if COHERE_API_KEY is available."""
    if not os.getenv("COHERE_API_KEY"):
        return None
    try:
        return CohereRerank(model="rerank-english-v3.0")
    except Exception:
        logger.exception("Failed to initialize CohereRerank")
        return None
```
