## 1. Symptôme Observé

Lorsqu'un développeur exécute `python utils/obsidian_monitor.py` (ou importe `utils.gcp_logging`) sur une machine locale qui n'est pas authentifiée auprès de Google Cloud Platform (absence de `gcloud auth application-default login` ou de `GOOGLE_APPLICATION_CREDENTIALS`), le script plante immédiatement avant même d'exécuter `main()` :

```text
google.auth.exceptions.DefaultCredentialsError: Your default credentials were not found.
```

---

## 2. Cause Racine (*Root Cause*)

Le client Google Cloud Logging est instancié dans la portée globale des deux fichiers :

```python
# utils/obsidian_monitor.py (L22) & utils/gcp_logging.py (L17)
logging_client = logging.Client()
logger = logging_client.logger('obsidian_file_monitor')
```

L'appel `google.cloud.logging.Client()` vérifie immédiatement les identifiants ADC (*Application Default Credentials*) au moment de l'import.

---

## 3. Contournement Immédiat (*Workaround*)

<Callout type="info" title="Indexer vos notes Obsidian sans Google Cloud">
Vous n'avez **pas besoin** de `utils/obsidian_monitor.py` pour indexer vos notes Markdown dans ChromaDB. Utilisez directement le graphe d'indexation `index_graph` qui ne dépend pas de Google Cloud Logging :

```python
import asyncio
from langchain_core.documents import Document
from retrieval_graph.index_graph import graph as index_graph

async def index_note(text: str, source: str):
    doc = Document(page_content=text, metadata={"source": source})
    await index_graph.ainvoke({"docs": [doc]})

asyncio.run(index_note("# Ma Note Obsidian\nContenu...", "ma-note.md"))
```
</Callout>
